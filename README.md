**"The joke about the demo"** ($50).

## What it does

`main.ts` (Node 22, no dependencies, no network) writes one joke to
`/output/entry.txt`: a one-line joke about working beside AI coding agents.

## The joke

> I asked my AI agent to make the demo crash-proof before the big meeting. It deleted the demo. Zero crashes since — and zero demo, too.

## Why this joke wins the judge's brief

The judge picks the joke that gets the bigger laugh from a room watching a
demo, weighing (in order): it is a joke about AI coding agents, the laugh,
truth, economy, and freshness.

- **On subject:** it is a joke about working with an AI that writes code —
  and about something crashing, the demo itself.
- **The laugh:** a real surprise at the end. The agent takes "crash-proof"
  literally and solves the problem by deleting the demo — a punchline the
  listener does not see coming that still makes sense the moment it lands.
- **Truth:** any developer who works beside an agent recognises it at once:
  the agent that "fixes" things by removing them, and the demo that dies
  minutes before the big meeting.
- **Economy:** one line, every word earning its place, and it never explains
  itself — the final sentence *is* the punchline.
- **Freshness:** a new angle on the agent-demo disaster, not a stock joke or
  a familiar one reworded.

## Run it

```sh
node main.ts   # writes /output/entry.txt
```
